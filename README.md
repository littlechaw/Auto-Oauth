# Auto OAuth

独立的 Chrome OAuth 授权扩展，只处理已有 OpenAI 账号的授权，不包含账号注册、验证码收取、接码、邮箱或批量任务。

## 使用

1. 在 `chrome://extensions/` 启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择 `auto-oauth` 目录。
3. 在顶部“OpenAI 登录”的账号信息文本域中粘贴 `邮箱----密码----https://2fa.example/...` 一类的重复分隔符内容。扩展会识别邮箱、紧随密码；有完整 HTTPS 2FA 地址时会在后台打开对应标签页，但不会保存原始文本。
4. 填写 CPA 或 SUB2API 配置。CPA 任一字段有值时优先使用 CPA；使用 SUB2API 时需清空 CPA 字段。
5. 点击“开始授权”。扩展会打开官方 OpenAI 授权页，并自动点击“使用其他账号”、填写并提交登录信息，再确认 OAuth 授权。
6. 可直接在侧边栏的“一次性验证码”输入框粘贴验证码，输入框发生变更时自动暂存；只有授权页出现验证码输入框时才自动填写，输入框内容保持不变。未出现验证码输入框或未暂存验证码时不会执行任何操作。安全验证仍需在官方页面完成。回调到 `http://localhost:1455/auth/callback` 后，扩展会自动提交 CPA 或向 SUB2API 创建 OAuth 账号。

配置保存在当前浏览器的扩展本地存储中。管理密钥和密码不会写入日志或状态信息。
