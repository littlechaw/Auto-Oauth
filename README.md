# Auto OAuth

独立的 Chrome OAuth 授权扩展，只处理已有 OpenAI 账号的授权

## 使用

1. 在 `chrome://extensions/` 启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择 `auto-oauth` 目录。
3. 在顶部“OpenAI 登录”的账号信息文本域中粘贴 `邮箱----密码----https://2fa.example/...----其他信息` 一类的重复分隔符内容，或 `邮件：name@example.com 密码：your-password` 这类带字段名的内容，然后点击“解析账号信息”。扩展会依次校验邮箱、读取密码，并仅在重复分隔符格式的第三段为完整 HTTPS 2FA 地址时替换一次性验证码上方的地址框；第四段及后续内容会忽略。邮箱中的 `\@` 会按 `@` 处理。未提供地址时会保留现有地址。点击“访问”会在新标签页打开该地址，原始账号信息不会保存。
4. 可同时填写 CPA 和 SUB2API 配置，无需清空任一方。
5. 点击“授权 CPA”或“授权 SUB”，扩展会打开对应平台的官方 OpenAI 授权页，并自动点击“使用其他账号”、填写并提交登录信息，再确认 OAuth 授权。
6. 可直接在侧边栏的“一次性验证码”输入框粘贴验证码，输入框发生变更时自动暂存；只有授权页出现验证码输入框时才自动填写并提交一次。提交后 4 秒仍停留在验证码页时，扩展会清空验证码并停止自动点击，供你修改后重新填写。安全验证仍需在官方页面完成。回调到 `http://localhost:1455/auth/callback` 后，扩展会自动提交 CPA 或向 SUB2API 创建 OAuth 账号。

配置保存在当前浏览器的扩展本地存储中。管理密钥和密码不会写入日志或状态信息。
